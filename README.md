# Dolor OS
*This repository contains all versions of Dolor OS.*
<br>
*If you wish to modify and/or republish Dolor OS, please give me credit for it.*  
**Dolor OS is an operating system made using only code, icons and everything.**

## Booting to the desktop
   -To boot to the desktop, you must type the following command into the Dolor OS Shell:
   ```Dolor
     boot
   ```
   -After you boot, there is a load screen where Dolor OS will load every resource including:<br>
     1. The background<br>
     2. The cursor<br>
     3. The font
   <br>
   -After the resources have been loaded, a message below the throbber will appear, saying `All resources loaded. Proceeding to Dolor OS.`
   
## The web browser
   -On the desktop, there is a globe icon. This is the web browser. It will only show websites that will display on an `<iframe>` HTML tag.<br>
        -An **`<iframe>`** (meaning **'Inline Frame'**) is an HTML tag to display websites or local files. It is affected by **CORS**
      
## The calculator
   -On the desktop, there is a calculator icon. This is the calculator. It can display the four basic operations `(+, -, *, /)` and all 10 digits `(0-9)`.

   -Once you click on the calculator icon, you will find that there is no way to get out. You must type `+-*/` and press `=`. **You will now be back on the desktop**.

## Exiting to the shell
   -At below the desktop, there is the **taskbar**. On the taskbar, there is a ***start menu button***. When you click it, the buttons will block your cursor. **That is why the start menu background is transparent.**
   -In the start menu, there are to buttons, **`Shell` and `Close`**. **`Shell`** exits you back to the shell, and **`Close`** closes the start menu.
   -If you decide to press **`Shell`**, there will be a loading screen where Dolor OS will unload its resources and shut down. **You are back in the Dolor OS Shell.**
