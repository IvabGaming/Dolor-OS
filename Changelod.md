# Dolor OS Changelog
## Shell
1. The Dolor OS Shell has been completely re-coded.
2. The shell is now on **version 2.1**, for the `echo` command has been added
### Echo
The `echo` command is structured like this:
```Dolor

  echo text

```
Of course, you can replace the text with whatever you want, however, **because Dolor OS does not utilize Electron, it cannot `echo` to a text file.**
